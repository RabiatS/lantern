# Age rating questionnaire

Recommended answers, and why. A language model running without a server has
no content filter beyond what its authors trained in, so the honest answer is
that it can produce unrestricted text. Most local model apps on the store are
rated 17+ for this reason, and a lower rating invites a rejection.

| Question | Answer |
| --- | --- |
| Cartoon or fantasy violence | None |
| Realistic violence | None |
| Prolonged graphic or sadistic realistic violence | None |
| Profanity or crude humor | Infrequent/Mild |
| Mature/suggestive themes | Infrequent/Mild |
| Horror/fear themes | None |
| Medical/treatment information | Infrequent/Mild (the first aid guide) |
| Alcohol, tobacco, or drug use or references | None |
| Simulated gambling | None |
| Sexual content or nudity | None |
| Graphic sexual content and nudity | None |
| Unrestricted web access | No |
| Gambling and contests | No |
| Made for Kids | No |

If App Store Connect offers a question about AI-generated or unrestricted
content, answer yes, which yields 17+. Otherwise the answers above yield 12+;
in that case set the rating to 17+ manually with the "Unrestricted" override
if the form provides one, and note it in the review notes.
